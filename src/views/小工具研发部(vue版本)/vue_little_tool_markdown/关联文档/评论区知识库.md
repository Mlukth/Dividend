# 评论区知识库 — 项目上下文

## 一句话
从视频评论区提取结构化观点 → 以**观点**为最小单位（非楼层）→ 分类标签 → 个人知识库 → 浏览+检索。

## 原始需求（用户逐字）
- 提供从评论区截取下来的文字，不修改原文，忠实保留
- 干两件事：提取核心要点 + 不修改原文的情况下分段（原文是直接从视频提取的一大段）
- 每个观点加带`[]`包裹的小总结辅助快速阅读
- 末尾提供所有小观点的汇总，保留`[]`
- 过滤无用的东西（后改为：全部保留不丢失，低信息量标记`[感谢][表情回应]`等但不删除）
- 以一个小评论/楼层为最小单位（后改为：**观点为最小单位**，楼层只是来源容器）
- 完成提取后进行统计：几个阵营、几种人、分别说什么观点、里面什么有效信息
- 慢慢迭代出自己的个人知识库
- 知识库存储 + 分类方案 + 后续检索读取
- 提示词可能两个都用：本地agent + 窗口AI（参考EnglishTranslationTool的双模式）
- 窗口AI和提示词使用参考 `小工具研发部(vue版本)/EnglishTranslationTool_v2_rebuild`

## 处理管线

```
原始评论楼层 → ①清洗(标记低信息量) → ②分段+[标签] → ③观点提取 → ④统计归类 → ⑤分类存储 → ⑥检索查询
```

1. **清洗**：不删除，用 `infoValue:1` + `infoType:"社交互动"` 标记纯感谢/表情/附和
2. **分段+标签**：核心提示词 `extractPrompt`，输入楼层文本 → 输出A(带[]标签分段原文) + 输出B(JSON)
3. **观点提取**：和②合在一个提示词里，viewpoints数组每个元素是一个观点
4. **统计归类**：`statsPrompt`，输入多个楼层JSON → 输出阵营分布/高频话题/共识/争议
5. **分类存储**：AI自由打标(tag+topics)，积累后人工收敛。存储为JSON文件
6. **检索查询**：分类浏览(话题树+标签云+infoValue筛选) + 关键词搜索

## 数据模型（观点为中心）

```
Viewpoint {
  id: "vp-xxx",
  speaker: "说话人",
  speakerRole: "UP主" | "评论者" | "提问者",
  tag: "观点简短标签（即[]里的内容）",
  original: "原文不修改，含表情",
  stance: "支持" | "反对" | "中立" | "提问" | "补充" | "感谢",
  infoType: "个人经验" | "事实陈述" | "推测" | "建议" | "辟谣" | "提问" | "社交互动",
  infoValue: 1-5,  // 5=一手数据 4=有依据分析 3=有参考价值 2=泛泛而谈 1=纯社交互动
  topics: ["话题1", "话题2"],  // AI自由打标
  source: {
    threadId: "楼层ID",
    platform: "B站" | "小红书" | ...,
    videoTitle: "视频标题",
    up主: "UP主名",
    date: "2026-04-23",
    completeness: "完整" | "不完整"
  }
}
```

楼层(Thread)退化为来源容器，一个楼层包含多个观点。检索时不按楼层搜，按观点搜。

## 提示词核心设计

### extractPrompt
- **输入**：一个楼层的评论文本（说话人：内容 \n 说话人：内容）
- **输出A**：人类阅读版——按话题分组，每段前加`[简短标签]`，保留说话人和原文
- **输出B**：JSON——threadId, completeness, topics[], viewpoints[{speaker, tag, original, stance, infoType, infoValue}], summary[]
- **跨平台**：复制提示词+原文 → 任意AI窗口 → 粘贴JSON → 解析入库

### statsPrompt（骨架，待细化）
- **输入**：多个楼层的JSON数组
- **输出**：阵营分布 + 高频话题 + 共识区 + 争议区 + 信息价值评分

## 竞品调研摘要

| 项目 | 做什么 | 差距 |
|------|--------|------|
| commentpulse | Chrome扩展，B站/YouTube评论分析(DeepSeek) | 面向UP主数据分析，不做知识库 |
| starseeker | Chrome扩展，小红书评论抓取导出CSV | 纯采集，无AI处理 |
| bilibili-summary | B站视频AI摘要(ASR+LLM) | 做视频摘要，不是评论提取 |

**结论**：无现成方案匹配"评论→观点→分类→知识库→检索"链，值得自建。
